## What works (verified on the MiSTer at 192.168.99.143)

Sun-2/160 target: VME CPU board, Rev Q PROM (`games/Sun-2/boot0.rom`), RD68011 at
20 MHz, 8 MiB, mono bwtwo 1152x900, VME SCSI disk `sd0` (hps_io VD 0) and an Emulex
MT-02 tape `st0` at target 4 (`rtl/sun2-common/sun2_mt02.sv`, VD 1, `.qic` images
from `tools/mktape`, OSD *Tape volume*). OSD *Scale*, V-Integer default. `Sun-2.qsf`
SEED 7.

SunOS 4.0 installs from the two-volume tape (`b st()` -> copy program -> miniroot ->
suninstall), the disk boots multi-user to `sun2 login:`, SunView (`suntools`) runs.
`doc/install-sunos.md` is the procedure, including the two miniroot steps the manual
omits (remount `/` by device, then empty `/etc/mtab`).

On the board: `/media/fat/_Unstable/Sun-2_20261002_tape3.rbf` (= the `816c187` RTL;
e7fc791f...), `_Unstable/Sun-2_tape_test3.mgl` mounts `games/Sun-2/sd0.img` + the 4.0
tape. `sd0.img` holds the installed 4.0 system (329 MB Micropolis layout); the user
planned to back it up and try a 1 GB root+swap disk themselves.

Tests: `make -C tb/verilator` (sdram 6729, block 67, kbd 20, mt02 62, scsi_odd 9 —

2. **The date.** The TOD (MM58167 on the VME SCSI board, `tod0 at vme24 0x200800`)
   starts from compile-time constants (`SUN2_RTC_*` in `rtl/sun2-common/sun2_config.vh`
   -> `mm58167 #(INIT_*)` in `rtl/sun2-vme/sun2_vme_scsi.sv`), so SunOS boots in Dec
   1987. hps_io already provides `RTC[64:0]` (MSM6242B BCD layout; bit 64 toggles
   on each update) — unconnected in `Sun-2.sv`. Add a runtime load port to
   `rtl/sun2-common/mm58167.v`, carry it up through `sun2_vme_scsi`/`top_fpga`,
   cross clk_mem -> cpu_clk. The MM58167 has no year: read
   `sun/sys/sun2/clock.c` (github.com/calmsacibis995/sunos-34-src, via `gh api`) for
   how SunOS forms the year before deciding what to load. Unit test + mutation.
3. **Sound: the keyboard bell.** `sun2_mister_kbd_mouse` already decodes the bell
   commands to `bell` — unconnected at `Sun-2.sv` (`.bell ()`); `AUDIO_L/R` are tied
   to 0. Drive a square-wave tone while `bell` is high (a Sun type-2/3 keyboard
   beeper; pick ~2 kHz, check `sundev/kbd.c` for KBD_CMD_BELL usage).
4. **Machine identity / Ethernet address.** The ID PROM (`rtl/sun2-common/idprom.v`)
   is constants: every machine is `8:0:20:1:6:E0`, serial 3442 — a problem once
   networking exists. Stock Main_MiSTer cannot hand the core the host MAC (hps_io has
   no such command). Plan agreed in chat: a Main_MiSTer hook (core name "Sun-2") reads
   eth0's MAC (`SIOCGIFHWADDR`, as `support/mac/mac_eth*.cpp` does for MacQuadra800,
   which builds 08:00:07 + host octets 3-5) and sends the low 3 bytes as a small
   download on a spare ioctl index at core start, *before* boot0.rom (the core
   holds reset until the PROM arrives); the core folds them into ETH3..5 and
   recomputes the checksum (XOR of bytes 0..14 = byte 15). Interim option: optional
   `boot1.rom` (ioctl index 64, auto-loaded by Main) as a whole ID PROM image.
   A Main_MiSTer fork/PR is the user's call — ask.
5. **Networking.** The on-board 82586 (`rtl/sun2-vme/sun2_ethernet.sv`, vendored
   `rtl/vendor/wish82586`) has its MII tied off in `Sun-2.sv` (`mii_rxd 4'd0`...).
   Follow the NeXT core: a frame mailbox in DDR3 at ARM 0x1FF00000 (DDRAM word
   0x03FE0000; DDRAM is unused here, tied off in `Sun-2.sv`), a fabric MII shim that
   streams frames between the 82586 and two rings, and a Main_MiSTer module cloned
   from `support/next/next_enet.cpp` (core-name gated, OSD network mode). Needs the
   Main_MiSTer change from item 4. Big item — plan first.
6. **Colour: the cgtwo.** The machine is meant to be a 2/160 colour. Frame buffer via
   the framework's `MISTER_FB` + `MISTER_FB_PALETTE` in DDR3; the PROM's colour
   console sequence (`_init_scolor` and the cgtwo registers) is in
   `doc/prom/README.md` / `doc/prom/boot0.lst`. Big item — plan first.
7. **Tape speed.** A full install takes ~1 hour. `sun2_mt02` fetches a block, then
   moves it (single buffer). Measure first — much of the time was `tar` making many
   small files (CPU-bound); if the tape matters, add a two-bank read-ahead as
   `rtl/vendor/wish5380/scsi_targ.sv` has.
8. **Timing margin.** cpu_clk meets by only +0.27 ns (SEED 7) on RD68011's
   ucode-ROM -> biu half-period path; the default seed missed by 25 ps. Any RTL change
   may need a seed sweep (`quartus_fit Sun-2 --seed=N`, then restore Sun-2.qsf — the
   fitter rewrites it). The DECA gained margin from a 53/47 duty split (`rtl/pll.v`
   is 52/48).

## Gotchas

- WSL: write a script, run `MSYS_NO_PATHCONV=1 wsl -d Ubuntu-24.04 -- bash
  /mnt/c/...`. Never bare `python3` in Git Bash; use
  `/c/Users/spam/AppData/Local/Programs/Python/Python39/python`. poppler and the m68k
  objdump are unpacked under `/home/dani/opt` (`LD_LIBRARY_PATH` to their lib dirs).
- The checkout is CRLF (`core.autocrlf=true`); `sed` anchors miss `\r` — avoid `$`.
- `rtl/vendor/*` are unmodified upstream copies: change upstream, re-copy.
- Board screenshots (`echo screenshot > /dev/MiSTer_cmd`) do not show the OSD;
  OSD changes are blind — verify by effect (e.g. the `.qic` fd position in
  `/proc/$(pidof MiSTer)/fdinfo`).
- Keyboard: L1-A = hold Right Alt+F1, press A. curses screens drop fast keys.
- SunOS facts: the Sun-2 disk ceiling is 1 GiB (21-bit six-byte CDBs); 4.0.3 tapes
  are upgrade-only; the 4.0 tape is the full install.
