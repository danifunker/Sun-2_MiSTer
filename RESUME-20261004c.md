## Gotchas met

* **CRLF.** Most RTL, `Sun-2.sv`, `README.md` and `CLAUDE.md` are CRLF in this
  checkout and the Edit tool's anchors miss there: edit them with a small
  script that normalises, replaces exact strings and restores the endings.
  Scripts are LF everywhere now (`.gitattributes`).
* **WSL** is shared with another session's simulations: stop only your own
  processes, by PID or a path unique to this repo.  Verilator ignores a
  `force` on nets it aliases through ports.
* **The board** (if the user allows it again): the OSD's Reset is F12, Up, Up,
  Enter; SunOS's `/dev/ttya` is `/dev/ttyS1` on the MiSTer, a way to get text
  out; a typed console line over 256 characters is cut short; root's old shell
  was csh, so `>&`, not `2>&1`.
